### 🏭 [Micro820 OT/ICS Security Assessment](https://github.com/samahorro/Micro820-OT-ICS-Security-Assessment)
> 🏆 Best Sponsor Project Award — CSUF ECS Innovation Showcase

Disney-sponsored security assessment of an Allen-Bradley Micro820 PLC simulating real-world attraction control infrastructure. Conducted red team operations including EtherNet/IP/CIP traffic interception, ARP spoofing, MITM simulation, unauthenticated runtime variable manipulation, and packet replay attacks. Designed a full defense-in-depth architecture with Suricata/EveBox IDS monitoring, VLAN segmentation, and firewall/ACL policies. Collaborated directly with Disney's Attractions OT Cybersecurity Team.
